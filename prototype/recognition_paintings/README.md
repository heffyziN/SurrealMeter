# Surreal Meter — prototype

Веб-прототип сервиса, который принимает изображение и с помощью zero-shot классификации CLIP оценивает его сходство с текстовыми описаниями стилей четырёх художников-сюрреалистов. В интерфейсе отображаются оценки пяти категорий (четыре художника и `other`), предупреждение при недостаточной уверенности и референсные записи из каталога.

## Технологии

- Python 3.10+
- Django 4.2
- SQLite
- PyTorch
- Hugging Face Transformers (`openai/clip-vit-base-patch32`)
- Pillow

## Запуск локально

1. Перейдите в каталог `prototype/recognition_paintings`.
2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   # Windows PowerShell: .venv\\Scripts\\Activate.ps1
   # macOS / Linux: source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

   Для некоторых конфигураций CPU, CUDA или Apple Silicon способ установки PyTorch может отличаться. При необходимости выберите команду установки на официальном сайте PyTorch.

4. Создайте локальную конфигурацию окружения (не добавляйте `.env` в Git):

   ```bash
   cp .env.example .env
   ```

   На Windows можно скопировать файл вручную. Для локального запуска настройки по умолчанию подходят; перед развёртыванием задайте собственный `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=false` и корректный список `DJANGO_ALLOWED_HOSTS`.

5. Создайте таблицы и загрузите нейтральные записи каталога:

   ```bash
   python manage.py migrate
   python manage.py loaddata paintings/fixtures/initial_artworks.json
   ```

6. Создайте администратора и запустите сервер:

   ```bash
   python manage.py createsuperuser
   python manage.py runserver
   ```

7. Откройте `http://127.0.0.1:8000/`. Админ-панель доступна по адресу `http://127.0.0.1:8000/admin/`.

При первом анализе изображения библиотека Transformers загружает веса и процессор CLIP из Hugging Face. Поэтому первому запуску анализа требуется доступ к сети; сама модель не включена в репозиторий.

## Данные каталога

В `paintings/fixtures/initial_artworks.json` сохранены 42 записи метаданных каталога: название, автор, год, категория и описание. Изображения картин в репозиторий не включены; добавляйте в админ-панель только материалы, которые разрешено хранить и распространять.

Подготовленный для проекта набор данных из 160 изображений (по 40 на каждого из четырёх художников) описан отдельно в аналитической документации. Этот fixture содержит 42 записи каталога и используется для первоначального заполнения базы данных при локальном запуске.

## Категории классификатора

- `dali` — Сальвадор Дали
- `magritte` — Рене Магритт
- `ernst` — Макс Эрнст
- `miro` — Жоан Миро
- `other` — реалистичные фотографии, пейзажи, портреты и реалистичная живопись

Классификатор сопоставляет изображение с текстовыми описаниями категорий. Полученные проценты являются оценками сходства в рамках этой модели, а не экспертным подтверждением авторства или подлинности произведения.
