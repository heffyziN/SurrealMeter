# Surreal Meter — сервис анализа изображений на сюрреализм

## О проекте

Surreal Meter — командный проект веб-сервиса для анализа изображений и определения их сходства с художественными стилями четырёх художников-сюрреалистов: Сальвадора Дали, Рене Магритта, Макса Эрнста и Жоана Миро.

Сервис принимает изображение пользователя, передаёт его на анализ модели CLIP и отображает оценки сходства с выбранными стилями. При низкой уверенности или преобладании категории `other` система показывает предупреждение. При успешной классификации пользователю также предлагаются примеры картин из каталога.

## Мой вклад

В рамках проекта я занимался продуктовой проработкой, организацией командной работы и подготовкой данных.

- Сформировал чек-лист из 12 визуальных признаков сюрреализма, который использовался при формализации предметной области и критериев отбора изображений.
- Описал три пользовательских сценария (Use Case) для арт-критика или модератора, студента художественного вуза и реставратора.
- Разработал User Journey Map из пяти этапов: от осознания потребности до повторного использования сервиса; зафиксировал действия пользователей, точки контакта, ожидания, барьеры и продуктовые решения.
- Подготовил в Miro Stakeholder Map, Data Flow Diagram и Process Flow Diagram, отразив заинтересованные стороны, движение изображения через компоненты приложения и последовательность обработки запроса.
- Организовал работу команды из четырёх человек: создал Kanban-доску на 32 задачи, составил двухнедельный план в формате диаграммы Ганта, проводил ежедневные короткие встречи и фиксировал статусы и блокеры. По итогам проекта все 32 задачи были завершены в срок; проведено 14 встреч, два блокера устранены в день обнаружения.
- Собрал датасет из 160 изображений четырёх художников — по 40 изображений на каждого.
- Структурировал метаданные в Google Sheets: автор, год написания, ссылка на источник и характеристика произведения (техника или материал, жанр, стиль либо визуальная особенность).
- Провёл первичную проверку качества датасета: проверил полноту ключевых полей, отсутствие повторяющихся изображений, доступность ссылок и соответствие каждой записи отдельному файлу изображения.
- Подготовил изображения и метаданные для последующей загрузки в Django Admin и проверки классификатора.

## Прототип

Прототип веб-приложения и инструкция по локальному запуску находятся в каталоге [`prototype/recognition_paintings`](prototype/recognition_paintings/README.md).

В прототипе используется Django, база данных SQLite и модель CLIP для zero-shot классификации изображений по четырём художественным стилям и категории `other`. Для вывода результатов приложение использует каталог картин с метаданными.

Подготовленный датасет проекта включает 160 изображений. В fixture прототипа для первоначального заполнения базы данных содержатся 42 записи каталога; сами изображения произведений в репозиторий не включены.

## Инструменты и методы

Miro, Google Sheets, WikiArt, Google Arts & Culture, Use Case, User Journey Map, Stakeholder Map, Data Flow Diagram, Process Flow Diagram, Kanban, диаграмма Ганта, структурирование метаданных, проверка качества данных и балансировка датасета.

## Технологии прототипа

Python, Django, SQLite, CLIP (`openai/clip-vit-base-patch32`), PyTorch, Hugging Face Transformers, Pillow.
